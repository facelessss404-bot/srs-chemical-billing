# S.B.R. CHEMICALS & OILS — GST Billing & Cloud ERP Suite

> Enterprise-grade Offline-First GST Billing, Customer Directory, and Chemical/Oil Inventory Management Suite built with React 19, TypeScript, Vite, Node.js, and Supabase Cloud PostgreSQL.

---

## 🌟 Highlights
- **100% Client Fidelity:** Exact 1-to-1 recreation of paper invoice stationery and legacy software screens for S.B.R. Chemicals & Oils.
- **Automated GST & Currency Engine:** Automatic CGST (9%) + SGST (9%) / IGST (18%), round-off calculation, and Indian English currency words generator.
- **Custom Chemical/Oil Units:** Pre-configured with **`Ltrs` (Liters)** default UOM for industrial chemicals, acids, and lubricants, with support for Kgs, Cans (5L/20L), and Barrels (200L).
- **Direct Supabase Cloud Sync:** Real-time multi-counter cloud database synchronization powered by Supabase PostgreSQL.
- **Exact A4 Paper Bill Print:** Pixel-perfect printable tax invoice matching physical stationery with Canara Bank details and authorized signatory.
- **Zero Dummy Data:** Shipped 100% clean and fresh for production client handover.

---

## 🚀 Quick Start (Local Run)

Double click:
```cmd
start-billing-suite.bat
```
The application will launch and automatically open `http://localhost:5000` in your browser.

---

## ☁️ Deploy to Vercel (1-Click)

1. Import this repository in [Vercel](https://vercel.com).
2. Add your Supabase environment variables:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. Click **Deploy**.
